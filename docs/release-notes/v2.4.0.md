# My Reading Room v2.4.0 — Reading Replay

Release date: 2026-11-18. This is a **complete application handoff**, not a deployed release. The ZIP includes all features from v2.3.9 and previous versions.

## Included

- New **Recaps** tab for Week (6 cards), Month (8 cards), Year (9 cards), with historical period navigation and guided story-slide controls.
- Highlights for reading time and pages, finished books, active days, page speed, time-of-day habits, streaks, reading modes, daily goals, genre preferences and top books. Annual includes a full genre/rating card; monthly includes compact genre bars; weekly includes goal success.
- **Historical Goodreads** finish dates/known years count as genuine completions, but no time, page or speed is invented before users began logging. All three activity modes preserve the v2.3.9 calculations and combine only once per session. Previous-period comparisons match elapsed days in unfinished periods.
- **View-only shared profiles** for Full permissions, while Summary-only profiles do not disclose individual records; clipboard summary only for the profile owner.
- 7-page `RECAP_MOCKUPS.pdf` and interactive self-contained `PREVIEW_SITE/index.html` (fictional data) for reviewing desktop and phone layouts before deployment.
- No notification scheduler, generated image cards, posting, or auto-sharing (optional future features).

## Before deploying from your current production v2.3.3

1. **Back up Supabase.** Run database migrations from `APP/supabase/` in this exact order: `UPGRADE_EXISTING_TO_V2.3.4.sql`, `UPGRADE_EXISTING_TO_V2.3.6.sql`, `UPGRADE_EXISTING_TO_V2.3.8.sql`, `UPGRADE_EXISTING_TO_V2.3.9.sql`. Skip any already-applied migration only after verifying schema and RPC definitions.
2. There is **no additional v2.4.0 SQL migration**. Do **not** run the fresh-install `schema.sql` over a populated database.
3. Deploy **only `APP/` from this v2.4.0 handoff** to the **existing** Vercel project. Intermediate front-end deployments are unnecessary.
4. Refresh/reopen the PWA so the new service worker cache is used. Test Week/Month/Year recaps and historic years, Goodreads finished counts, account isolation/Full versus Summary sharing, daily goal history and chapter log features.

## Validation and limitations

- **177/177** local Node automated tests passed (`cd APP && npm test`); render smoke passed.
- Standalone preview generated by the same renderer and inspected in Chromium using in-memory HTML; desktop 1280px, mobile 390px and narrow 320px mockups had no page-level horizontal overflow.
- Local server navigation was blocked by the browser sandbox; no production visual testing and no live Supabase RLS/Auth/integration testing occurred.
- The visual PDF/HTML uses **fictional sample data**, not your Goodreads CSV or actual accounts.
